# aurum-data 云函数

`aurum-data` 为望潮小程序自动读取已经公开发布并脱敏的最新市场快照：

1. 私有数据仓库在交易日自动抓取并通过审核后发布到固定 GitHub Pages 地址。
2. 定时触发器 `data-snapshot-warm`（每 30 分钟）主动回源并写入数据库缓存；用户打开页面时优先读内存 / 10 分钟内数据库缓存。
3. 函数再次执行小程序专用脱敏，拒绝数量不足、状态错误或结构异常的半成品；保留公开研究观察字段（如港股 `publicAnswer`、黄金 `pricePlan`）。
4. 上游短暂不可用时，返回数据库/内存中的上一份可用快照并带 `warning`；小程序仍可回退随包离线数据，页面不会空白。

函数超时建议在云开发控制台设为 **10 秒**（CLI 不一定写入 `config.json` 的 timeout）。
线上读路径为「内存/数据库缓存优先、回源后台化」，并带 `SOURCE_REVISION` 供 `health` / 发布审计核对。
部署后请确认触发器已启用，并确保 `data_snapshot_cache` 集合可写（函数会尝试自动创建）。
每次正式上传前运行 `npm run audit:release`，核对 Pages / 本地 / 小程序 `updatedAt` 与金额单位规范化。

下拉刷新会强制检查公开快照；正常页面跳转共用客户端缓存，避免重复请求。
