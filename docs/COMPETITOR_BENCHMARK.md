# 望潮 Aurum · 对标标杆与适老化三问设计规范（2026-11-27 更新）

## 一、核心体验铁律
1. **适老化全屏大字**：首页铺满整屏（`118rpx` 大号搜索栏 + `28rpx` 港美A热门股胶囊 + 撑满主体空间的 `32rpx` 大图标九宫格 + `26rpx` 底部免责声明），零术语、零反问。
2. **先答三问，再给辅助依据**：每个模块与每只个股详情页，首屏第一眼统一用大白话讲清三件事：
   - **① 什么标的**：中文简称 + 代码 + 一句话说清公司靠什么赚钱
   - **② 怎么判断**：赚钱质量 / 分红连续性 / 招股进度与破发风险提示（合规客观，不喊单荐股）
   - **③ 参考价位**：最新收录报价 + 近 60/90 日真实高低区间 + 买一手本金 / 投1万元年分红金额
   - **下方辅助区**：统一归入「辅助判断参考（数据 · 图表 · 近况）」，承载历史走势曲线、财务质量、分红档案与官方公告动态。
