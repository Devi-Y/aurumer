# 望潮 Aurum · 六大核心标杆全方位对标与落地规范（2026-11-28 0.4.6 二期与全流程打磨）

## 一、核心体验铁律
1. **适老化全屏大字**：首页与各二级页保持清晰留白，全站消除小于 `24rpx` 的碎小文字，生僻金融黑话全面翻译成生活大白话。
2. **先答三问，再给图表与试算**：每个模块列表行与每只个股详情页，首屏第一眼统一讲清三件事：
   - **① 买什么**：中文简称 + 完整代码 + 主业定位短标签 + 大师持仓/派息频次微标
   - **② 能不能买**：醒目白话结论章（`偏便宜·可关注` / `分红稳·偏便宜` / `值得申购` / `风险偏高·暂不追`；快照超 36 工作小时自动降级为 `数据待更新`）
   - **③ 以多少钱买**：直接展示基于真实公开财报、股息率回推或技术波动算出的参考低位区与高位区
3. **只抄精华、拒绝鸡肋**：凡是普通投资者高频刚需的「算账试算、月历排期、同业横评、保荐人胜率」全部零门槛内置；凡是脱离小程序定位或触碰合规红线的「OCR 传图记账、模拟撮合五档盘口、期权希腊字母链、券商实时孖展爬虫、分析师目标价」一律不折腾。
