# 望潮 Aurum｜全球竞品对标与合规落地参考

更新日期：2026-08-12

本文档把截图中的最初诉求、当前 `PRODUCT_PLAN.md` 定位，与全球可对标的参考产品做**字段级对照**，并标注望潮在合规边界内**可学 / 不可抄 / 需改造**的落点。

> 本轮实现状态：P1–P1.7 小程序缺口已按「不重复建设」原则补齐；仍待人工的是 `ACCEPTANCE_EVIDENCE.md` B/C 节。

> 合规前提（与 `ACCEPTANCE_EVIDENCE.md` 一致）：望潮是**信息整理与研究辅助**工具，不构成投资建议；会员交付跟踪与复盘工具，不交付具体买卖建议或收益预测；A 股模块与聪明人 WHY/HOW 在提审前须取得专业合规结论。

## 一、最初诉求回顾

| 模块 | 用户最初想要的样子 |

| 形态 | 网页 + 微信小程序 |
| 港股 | 打新、股票信息、打新/暗盘/首日预测、历史数据回溯 |

望潮当前公开结构（`README.md`）已覆盖上述模块骨架；差距主要在**预测深度、回溯完整度、名人 WHY/HOW 自动化、以及会员跟踪闭环**。
