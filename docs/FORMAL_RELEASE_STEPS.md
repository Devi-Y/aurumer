## 你现在要做的 4 步（约 10 分钟提交）

### 1. 类目与隐私（若尚未完成，提审可能被拦）

1. 登录 https://mp.weixin.qq.com/ → 望潮 AppID `wx4329d5e05c2f13f9`
2. **设置 → 基本设置 / 服务类目**：确认覆盖当前内容（含 A 股公开资料整理范围）
3. **设置 → 服务内容声明 → 用户隐私保护指引**：与 `MINIPROGRAM_PRIVACY_SUPPLEMENT.txt` 一致并已发布

### 2. 选开发版 → 提交审核

1. **管理 → 版本管理**
2. 在「开发版本」找到 **0.2.46**
3. 点 **提交审核**
4. 功能页面：勾选首页、栏目、列表、详情、会员、工作台等主要页
5. 测试账号：填给你和审核可用的微信号（若要求）
6. **版本描述 / 备注**：打开仓库根目录 `MINIPROGRAM_REVIEW_COPY.txt`，复制「七、审核备注建议」整段粘贴

### 3. 等审核通过

- 通常数小时到数天；驳回按意见改类目/文案/范围后再提
- 审核通过后会出现在「审核版本」

### 4. 正式发布（审核通过后点一次）

1. **版本管理 → 审核版本**
2. 点 **发布**
3. 确认全量发布（非灰度亦可）
4. 发布后用正式版扫码抽查：首页数据、会员入口、工作台
