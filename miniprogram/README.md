# 望潮微信小程序

望潮客户端只开发微信小程序，不开发、打包或发布 Android/iOS 独立 App；Android 与 iOS 只表示用户在对应手机的微信客户端内运行望潮小程序。小程序采用全原生链路：首页核心入口 → 分类 → 列表 → 详情；黄金追踪固定第四，机构持仓固定最后并按港股 3、美股 5、A 股 3 展示。公开市场数据先立即显示随版本打包的脱敏快照，再由免费云函数 `aurum-data` 自动读取网页已发布的最新公开快照；网络异常时自动保留离线数据，不打开外部网页。

## 免费与会员边界

公开页展示基于公开资料的研究观察：港股申购研究结论、黄金价格观察区、美股/A 股事实与研究口径，统一标注为研究参考而非强制下单指令或个性化投资建议。会员首期只销售研究工具：跨设备跟踪清单、用户自己的决策档案/复盘与个人记录导出；权益到期后仍可只读和导出。荐股、收益预测或不按公开资料的个性化买卖指令不作为会员商品交付。提审与正式运营前须完成类目核验与专业合规意见；证据清单见仓库根目录 `ACCEPTANCE_EVIDENCE.md`。

支付采用与问岳相同的普通小程序最短收银台体验：客户端只调用一次 `preparePurchase`，免费云开发以 `cloudPay.unifiedOrder` 下单后，小程序立即通过 `wx.requestPayment` 拉起微信收银台；付款完成后客户端不再阻塞轮询查单，直接返回成功界面，权益由支付通知、服务端主动查单和幂等账本在后台同步。不配置年度“道具”，也不由望潮代码保管商户密钥或证书。客户端成功回调不作为发放依据；只有订单号、商户号、AppID、OpenID、套餐、金额和交易状态全部匹配，数据库事务才会延长权益。

当前只提供单次购买的 365 天年度研究会员，价格 1288 元/年，不做自动续费。自动续费当前要求小程序首次发布满 90 天、完成认证备案且近 30 天日均 DAU ≥ 1 万，首版不满足准入条件。

首页采用手机优先的全宽信息流：顶部“今日重点”只保留一句话结论和三项核心数字，可原地展开四个市场重点；下方只保留 3×2 的六个核心入口并删除全部说明小字，标题依次为港股打新、美股投资、A 股收息、黄金追踪、年费会员、机构持仓。六个入口使用六个不同语义和颜色的图标，黄金追踪固定第四、机构持仓固定最后；“我的关注”和“我的记录”合并为网格外的一条“我的研究记录”。栏目页先给结论再进入分组，列表页只保留结论、标的和可比数据；详情页默认只显示一句话结论、四项关键数据和图示，事实、WHY/HOW 与风险按需展开。会员页压缩为唯一价格、期限和微信支付入口，工作台用“关注 / 想法”双标签切换，协议正文默认收起；小屏手机、常规手机及平板均有响应式边界。

小程序离线快照在生成时清洗内部策略、评分与模型私货，保留允许公开的研究观察字段（如港股 publicAnswer、黄金 pricePlan 观察区）。历史价格序列会采样瘦身以控制包体。网页公开镜像的完整数据结构不因此改变。

## 公开快照更新

线上小程序会通过 `aurum-data` 自动读取网页最新公开快照，不需要因数据变化重复发版。免费数据任务在北京时间工作日 09:30（美股收盘后）和 16:30（A 股、港股收盘后）自动更新公开快照；云函数使用 10 分钟缓存，并在失败时回退离线数据。若要同步本地离线备用数据，在仓库根目录执行：

```bash
npm run sync:latest
npm run check:mini
npm run check:payment
```

`sync:latest` 会下载已公开快照，再复用云函数的同一套清洗器写入 `miniprogram/data/live-snapshot.js`。运行时云数据和离线快照都会删除内部策略、动作价、评分与模型字段。
