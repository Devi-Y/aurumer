# 望潮微信小程序

望潮客户端只开发微信小程序，不开发、打包或发布 Android/iOS 独立 App；Android 与 iOS 只表示用户在对应手机的微信客户端内运行望潮小程序。小程序采用全原生链路：首页核心入口 → 分类 → 列表 → 详情；黄金追踪固定第四，机构持仓固定最后并按港股 3、美股 5、A 股 3 展示。公开市场数据先立即显示随版本打包的脱敏快照，再由免费云函数 `aurum-data` 自动读取网页已发布的最新公开快照；网络异常时自动保留离线数据，不打开外部网页。

## 历史快照整理

线上小程序会通过 `aurum-data` 自动读取网页最新公开快照，不需要因数据变化重复发版。后台可按日整理已完成批次，不承诺实时或每日新报价；云函数使用 10 分钟缓存，并在失败时回退离线数据。若要同步本地离线备用数据，在仓库根目录执行：

```bash
npm run sync:latest
npm run check:mini
npm run check:payment
```

`sync:latest` 会下载已公开快照，再复用云函数的同一套清洗器写入 `miniprogram/data/live-snapshot.js`。运行时云数据和离线快照都会删除内部策略、动作价、评分与模型字段。
