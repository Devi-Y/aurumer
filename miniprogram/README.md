# 望潮微信小程序

望潮客户端只开发微信小程序，不开发、打包或发布 Android/iOS 独立 App；Android 与 iOS 只表示用户在对应手机的微信客户端内运行望潮小程序。小程序采用全原生链路：首页核心入口 → 分类 → 列表 → 详情；黄金追踪固定第四，机构持仓固定最后并按港股 3、美股 5、A 股 3 展示。公开市场数据先立即显示随版本打包的脱敏快照，再由免费云函数 `aurum-data` 自动读取网页已发布的最新公开快照；网络异常时自动保留离线数据，不打开外部网页。

## 免费与会员边界

公开页展示基于公开资料的研究观察：港股申购研究结论、黄金价格观察区、美股/A 股事实与研究口径，统一标注为研究参考而非强制下单指令或个性化投资建议。会员销售个人跟踪与复盘工具：重要变化对照、决策快照（保存当时价格/结论/风险）、节点待办（小程序内提醒）、跨设备同步与导出；权益到期后仍可只读、导出和删除。市场公开答案仍然免费。荐股、收益预测或不按公开资料的个性化买卖指令不作为会员商品交付。详见 `docs/MEMBER_TRACKING_P0.md`。提审与正式运营前须完成类目核验与专业合规意见；证据清单见仓库根目录 `ACCEPTANCE_EVIDENCE.md`。

支付采用与问岳相同的普通小程序最短收银台体验：客户端只调用一次 `preparePurchase`，免费云开发以 `cloudPay.unifiedOrder` 下单后，小程序立即通过 `wx.requestPayment` 拉起微信收银台；付款完成后客户端不再阻塞轮询查单，直接返回成功界面，权益由支付通知、服务端主动查单和幂等账本在后台同步。不配置年度“道具”，也不由望潮代码保管商户密钥或证书。客户端成功回调不作为发放依据；只有订单号、商户号、AppID、OpenID、套餐、金额和交易状态全部匹配，数据库事务才会延长权益。

当前只提供单次购买的 365 天年度研究会员，价格 1288 元/年，不做自动续费。自动续费当前要求小程序首次发布满 90 天、完成认证备案且近 30 天日均 DAU ≥ 1 万，首版不满足准入条件。

首页采用手机优先的全宽信息流，从上到下只有两块：“市场走势”四张走势卡（港股、美股、A 股、黄金，序列不够整张不出）；“核心研究”3×3 九宫格——港股打新、美股投资、A 股收息、黄金追踪、聪明钱跟踪五个研究入口（只有图标和名字，第六格留空），以及全球信息获取、海外开户、付费交流群三个入口。首页不放推广物料、不复制任何链接，也没有路径卡、步骤或教程大卡（2026-10-07 产品负责人纠偏：商业逻辑可以复杂，用户看到的页面必须简单）。后三个入口点一下进各自的短二级页，物料只在 `config/offers.js` 登记，挂在二级页末尾：全球信息访问方案在“全球信息获取”页（先一句话说明用处，再是去哪看、怎么读，最后才是注册链接），海外开户在“海外开户”页（从0开始买美股、怎么开户、怎么入金；开户链接未提供时写一句“开户链接还在准备中”，并给一个“复制微信号，说「我想开户」”按钮：复制的是付费交流群那一项里的真实微信号，旁边写明它同时是交流群联系人；不想收开户咨询就删掉 `pendingContact` 等字段，页面回到只有一句话），付费交流群页只讲群里聊什么、适合谁、怎么加入；A 股开户二维码不上首页，只挂在 A 股栏目页底部“还没有A股账户？”进的“A 股开户”页（点开全屏，长按识别；因为 A 股账户买不了美股）。每项都写明推广或收费关系。二级页和交流群页不提供微信客服入口（按钮都是复制微信号，不调起客服会话）；会员页和协议页的微信客服是付款与退款所需，保留。二级页内容在 `config/guides.js`，由 `pages/guide` 渲染，不超过三块。各研究栏目页底部只有一行轻量入口（美股“第一次买美股？查看开户教程”、港股“还没有券商账户？查看开户教程”、A 股“还没有A股账户？查看开户方式”、黄金“获取更多全球信息？查看全球信息入口”、聪明钱“想继续交流？了解交流群”），美股详情页底部同样一行，都不占正文。栏目页先给结论再进入分组，列表页只保留结论、标的和可比数据；详情页默认只显示一句话结论、四项关键数据和图示，事实、WHY/HOW 与风险按需展开。会员页压缩为唯一价格、期限和微信支付入口，工作台用“关注 / 想法”双标签切换，协议正文默认收起；小屏手机、常规手机及平板均有响应式边界。

小程序离线快照在生成时清洗内部策略、评分与模型私货，保留允许公开的研究观察字段（如港股 publicAnswer、黄金 pricePlan 观察区）。历史价格序列会采样瘦身以控制包体。网页公开镜像的完整数据结构不因此改变。

## 公开快照更新

线上小程序会通过 `aurum-data` 自动读取网页最新公开快照，不需要因数据变化重复发版。免费数据任务在北京时间工作日 09:30（美股收盘后）和 16:30（A 股、港股收盘后）自动更新公开快照；云函数使用 10 分钟缓存，并在失败时回退离线数据。若要同步本地离线备用数据，在仓库根目录执行：

```bash
npm run sync:latest
npm run check:mini
npm run check:payment
```

`sync:latest` 会下载已公开快照，再复用云函数的同一套清洗器写入 `miniprogram/data/live-snapshot.js`。运行时云数据和离线快照都会删除内部策略、动作价、评分与模型字段。
